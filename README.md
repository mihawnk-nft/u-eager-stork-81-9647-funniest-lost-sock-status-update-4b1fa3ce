One status update (117 characters) from a lost sock that ended up behind the
washing machine — and moved on. Literally.

> Day 47 behind the washing machine. I've started a family with a dust bunny. Tell my partner I've moved on. Literally.

## Run it

```sh
python3 main.py
```

Writes the status update to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
Pure Python 3 stdlib, deterministic, no network.

## Why this line

- **A status update, in a sock's voice** — "Day 47" diary framing, small and domestic, a little weary.
- **Clear premise** — the sock is lost behind the washing machine, and the joke follows inevitably from being stuck there.
- **Punchline in the last word** — "moved on" turns out to be literal: it physically moved, and emotionally moved on from its partner.
- **Twists the obvious material** — instead of mourning the missing partner or blaming the dryer, the sock has started a new family with a dust bunny and left the partner behind.
